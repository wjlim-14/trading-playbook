# Trading History Module

Comprehensive trade log replacing the old Notion/Google Sheets workflow.

**Status:** Active
**Priority:** High

## Scope
- Log all trades: entry, exit, SL, TP, R-multiple, market, direction, mood, notes, review
- Support for Crypto, Forex, US Stocks, Bursa Malaysia
- Fast data entry — under 2 minutes per trade
