# Work & Business

## J.Tradebook
- Personal trading dashboard — not a business, no revenue, no external users
- Replacing old Google Sheets workflow with a proper web app
- Stack: HTML/CSS/JS frontend, Vercel serverless backend, Supabase PostgreSQL

## 4 Core Modules
1. **Risk Calculator** — eliminate manual formula math before entering trades
2. **Trading History** — comprehensive trade log with full entry/exit/SL/TP/R-mult data
3. **Market Sentiment** — KLCI (Malaysia) + US markets in one view; exploring Moomoo API for live data
4. **Performance Dashboard** — review past trades, identify bad patterns, improve entry rules

## Tools
- **TradingView** — charting, drawing, setting alerts and signals
- **Telegram** — personal notes to self (trade ideas, observations)
- **Notion** — legacy trade records (being phased out)
- **Moomoo** — potential API source for KLCI/Malaysia market data

## Markets Traded
- Bursa Malaysia (KLCI focus)
- US Stocks
- Crypto
- Forex
